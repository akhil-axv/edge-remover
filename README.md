# Linux Command Reference

A visual quick-reference page for common Linux terminal commands.

## Open the reference

Open `linux_commands_reference.html` in a modern web browser. It is a standalone HTML page and does not require a package manager or build step.

## Topics

The reference is organized into command groups and short examples. Read each command before running it, especially commands that modify files, permissions, packages, or system settings.

## Safety

- Test unfamiliar commands in a disposable folder or virtual machine.
- Review paths and options before running commands with elevated privileges.
- Keep backups before destructive file operations.
- Do not paste commands from untrusted sources without understanding them.

## Contributions

Keep examples short, accurate, and compatible with the distributions named in the description.
