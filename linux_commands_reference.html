Linux Command Reference

# essential commands — categorized & annotated

01 File & Directory Management
ls
Lists files and directories in current folder
ls -la
cd [dir]
Changes your current working directory
cd ~/projects
pwd
Prints the full path of your current directory
pwd
mkdir [name]
Creates a new directory
mkdir -p src/utils
rm [file]
Removes a file; use -r to delete directories
rm -r dist/
cp / mv
Copy or move/rename files and directories
mv old.txt new.txt
touch [file]
Creates a new empty file instantly
touch index.js
02 Viewing & Editing Files
cat [file]
Dumps entire file contents to the terminal
cat config.yaml
less [file]
Page through large files without loading all at once
less server.log
head / tail
Shows first or last lines of a file; tail -f for live logs
tail -f app.log
nano / vim
In-terminal text editors for quick edits
vim ~/.bashrc
03 System & Process Monitoring
top / htop
Real-time view of processes, CPU, and RAM usage
htop
ps aux
Snapshot of all currently running processes
ps aux | grep node
kill [PID]
Terminates a process by its process ID
kill -9 3821
df -h
Shows disk space usage in human-readable format
df -h /
free -m
Displays RAM usage in megabytes
free -m
04 Networking
ping [host]
Checks connectivity to a server or IP address
ping google.com
ip a
Shows network interfaces and IP addresses
ip a
curl [URL]
Transfers data to/from a server; great for API testing
curl -X GET api/v1
wget [URL]
Downloads files from the internet
wget https://…
05 Permissions & Ownership
sudo
Runs a command with root/admin privileges
sudo apt update
chmod
Changes file access permissions
chmod +x script.sh
chown
Changes file owner and group
chown user:group f
06 Search & Filtering
grep [pat]
Searches for a string or pattern inside files
grep -r "error" logs/
find [path]
Searches for files in a directory hierarchy
find . -name "*.js"
